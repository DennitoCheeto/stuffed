# Credits and licences

Everything you see and hear in Stuffed is made in code in this repository, except three free
fonts (below). There are no purchased asset files.

| What | Source | Licence |
|------|--------|---------|
| Characters, enemies, pickups, arena | Drawn in code (felt style, `src/puppet/`, `src/enemies/looks/`) | Part of this project |
| Sound effects (whff, tsing, thup, plop, plip, fwip, zwiip, honk, quack, deflate, jingle, boss horn, stomp) | Synthesized in code (`src/audio/sfx_bank.gd`) | Part of this project |
| Music (title, run and boss-fight loops) | Synthesized live in code (`src/audio/music_player.gd`) | Part of this project |
| Fonts: Fredoka (headings), Patrick Hand (hand-written), Nunito (body text), `assets/fonts/` | Google Fonts repository, https://github.com/google/fonts (`ofl/fredoka`, `ofl/patrickhand`, `ofl/nunito`); licence texts next to the fonts | SIL Open Font License 1.1 |
| UI pieces (felt panels, sewn buttons, tags, stickers, tape, photos) | Drawn in code (`src/ui/style/`) | Part of this project |
| Test framework (not shipped) | GUT 9.7.1 (`addons/gut/`) | MIT |

If an external file is ever added (for example a CC0 music track in M6), list it here with its
source URL and licence.
