# Credits and licences

Everything you see and hear in Stuffed is made in code in this repository. There are no
purchased or downloaded asset files.

| What | Source | Licence |
|------|--------|---------|
| Characters, enemies, pickups, arena | Drawn in code (felt style, `src/puppet/`, `src/enemies/looks/`) | Part of this project |
| Sound effects (whff, tsing, thup, plop, plip, fwip, zwiip, honk, quack, deflate, jingle) | Synthesized in code (`src/audio/sfx_bank.gd`) | Part of this project |
| Music (title and run loops) | Synthesized live in code (`src/audio/music_player.gd`) | Part of this project |
| Font | Godot's built-in default font | MIT (Godot Engine) |
| Test framework (not shipped) | GUT 9.7.1 (`addons/gut/`) | MIT |

If an external file is ever added (for example a CC0 music track in M6), list it here with its
source URL and licence.
