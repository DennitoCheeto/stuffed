# Stuffed (working title)

A PC bullet-heaven roguelite: brave stuffed animals go on short, chaotic expeditions into a world overrun by
zombie plushies, bring home buttons and stuffing to grow their pillow-fort town, and defend it from the horde
at night.

- Vision: [docs/specs/00-product-vision.md](docs/specs/00-product-vision.md)
- How we build it: [docs/process.md](docs/process.md)
- Status: [docs/status.md](docs/status.md)

## Play

Download `Stuffed-windows.zip` from the **latest** release, unzip it, and run `Stuffed.exe`.

## Develop

- Godot 4.7.2 (standard). Open `project.godot`, press F5.
- Run all tests: `tools/test.sh` (set `GODOT` to your Godot console binary if it isn't the default path).
